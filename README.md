# Mahdi Same — Personal Portfolio

A GitHub Pages-ready personal portfolio for Mahdi Same, combining academic/research and industrial/R&D experience.

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## GitHub Pages
Upload the contents of this folder to a GitHub repository and enable GitHub Pages from the repository's Settings → Pages.
